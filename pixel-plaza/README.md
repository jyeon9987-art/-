# 픽셀광장

나만의 픽셀 캐릭터를 만들어 입장하고, 방을 돌아다니며 실시간으로 채팅하는 온라인 광장입니다.

## 실행

```bash
npm install
```

```bash
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

## 들어 있는 기능

- **캐릭터 만들기**: 성별, 체형, 피부색, 얼굴, 머리 모양/색, 상의/색, 하의/색, 악세서리. `🎲 랜덤` 으로 자동 선택. 마지막 캐릭터와 닉네임은 브라우저에 저장됩니다.
- **방 3개**: 광장, 카페, 라운지. 노란 타일(포털)로 걸어가면 방을 옮깁니다.
- **이동/채팅**: 타일을 누르면 길을 찾아 걸어가고, 채팅은 말풍선과 대화 기록에 표시됩니다.
- **옷 갈아입기**: 입장 후에도 캐릭터를 바꿀 수 있습니다.
- **광고판**: 방마다 협찬 배너 자리가 있습니다. (아래 참고)
- PC와 모바일 화면 모두 지원합니다.

## 광고/협찬 배너 바꾸기

`sponsors.json` 을 수정하고 서버를 다시 시작합니다.

```json
"plaza-1": { "title": "브랜드 이름", "sub": "한 줄 문구", "color": "#ff7aa2", "url": "https://example.com" }
```

- 자리 이름: `plaza-1`, `plaza-2`, `cafe-1`, `lounge-1`, `lounge-2`
- `url` 을 넣으면 배너를 눌렀을 때 새 탭으로 열리고 클릭 수가 집계됩니다.
- `http://localhost:3000/api/stats` 에서 현재 접속자, 최고 동시 접속자, 방별 인원, 배너별 클릭 수를 볼 수 있습니다. 협찬사에게 보여 줄 수치로 쓸 수 있습니다. (서버를 재시작하면 초기화됩니다.)

## 방/가구 추가하기

`rooms.js` 의 `map` 은 글자 하나가 타일 하나입니다. 글자 뜻은 파일 맨 위 주석에 있습니다. 새 가구는 `public/scene.js` 의 `FURN` 에 상자·둥근 덩어리·작은 장식의 목록으로 추가합니다. 벽지 색과 창문 위치는 방마다 `wall` 항목에서 정합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `server.js` | 정적 파일 제공 + WebSocket 서버 (입장, 이동, 채팅, 방 이동 검증) |
| `rooms.js` | 방 지도와 포털 |
| `sponsors.json` | 광고판 내용 |
| `public/spec.js` | 캐릭터 선택지 (서버 검증과 공유) |
| `public/avatar.js` | 픽셀 미니미 그리기 (대각선 앞모습/뒷모습, 걷기 동작) |
| `public/scene.js` | 가구, 바닥 타일, 벽지·창문이 있는 방 배경 그리기 |
| `public/game.js` | 화면 그리기, 입력, 네트워크 |

## 아직 없는 것

- 계정/로그인이 없습니다. 닉네임은 중복될 수 있고 접속 정보는 서버 메모리에만 있습니다.
- 신고, 차단, 금칙어 필터 같은 운영 도구가 없습니다. 공개 운영 전에 꼭 필요합니다.
- 서버 한 대 기준입니다 (동시 접속 300명 제한).
